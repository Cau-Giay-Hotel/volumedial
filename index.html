FAQ
Why does it need the Accessibility service?

That is the only way an Android app can react to a physical volume key press before the system panel appears, and it is how the app checks the foreground package so it can skip the apps you excluded. It does not read screen content, record what you type, or send anything off the device.

Is anything locked behind a purchase?

No. Every dial style, color option, gradient, RGB effect, preset and launcher icon is available from the first launch. There is no premium tier and no ads.

Does it make volume more precise?

No, and we would rather say so. Android decides how many volume steps your device has, and Volume Dial uses the same ones. What changes is how that control looks, feels and where it appears.

What is the Notification access permission for?

Only for showing the currently playing track title on the dial. Media integration is optional — skip the permission and everything else still works.

Where are my presets stored?

On your device. You can export a preset to a file and import it back, but nothing is uploaded and there is no account to create.
